What I’ve built in Claude Code

Three builds, end to end. One is an agent, one is an app, and one is a workflow I use on this site.

  • Agent

    Job Agent

    A job-search pipeline I built for my own search. It scans public company job boards (Greenhouse, Lever and Ashby), filters by title, location, years required and sponsorship language, and checks employers against H-1B and E-Verify records. For the best matches it drafts a tailored one-page resume and cover letter from a fact file, so every bullet traces back to a real result, then lint-checks the format. Nothing is sent until I approve it, and the final submit click is always mine.

    Claude Code · Python · Node.js

  • App

    GlucoTrack

    A calorie and carb tracker for Type 1 diabetes, built as a web app. It logs food and glucose readings, estimates a carb bolus, tracks time in range and weight trends, saves favorite meals and recipes, and looks up foods online and by barcode through the USDA and Open Food Facts databases.

    Claude Code · JavaScript · USDA & Open Food Facts APIs

  • Workflow

    Role-targeted portfolio builder

    A Claude Code workflow that turned this portfolio into role-specific versions for marketing, business operations, strategy and product marketing. It rewrites each page’s results, tools and case studies for the role, keeps job titles and dates unchanged, and uses only my real numbers.

    Claude Code · Python
